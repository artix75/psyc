psyc-cc

SYNOPSIS

Usage: psyc-cc [OPTIONS] [SOURCE] [-- GCC_OPTS]

DESCRIPTION

Compile a C source file against Psyc library.

OPTIONS

  • --is-lib
    Compile a library instead of an executable
  • --cflags
    Print CFLAGS and exit
  • --ldflags
    Print LDFLAGS and exit
  • --c++
    SOURCE is a C++ source
  • -o, --output PATH
    Output path
  • -s, --static
    Use static library
  • -p, --dry-run
    Only print command whithout executing it
  • -q, --quiet
    Quiet mode
  • -h, --help
    Print this help
